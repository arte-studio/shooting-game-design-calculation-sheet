# 歯車列 設計計算シート

赤（駆動）・緑（中間）・青（出力1）・黄（出力2，内歯車）の4歯車からなる歯車列について，
条件を満たす **モジュールと歯数の組み合わせ** をアルゴリズムで探索し，結果をブラウザ上の GUI で確認するツール。

## 使い方

```bash
python3 -m http.server 8765      # このディレクトリで実行
# ブラウザで http://127.0.0.1:8765/index.html を開く
```

`index.html` をそのまま開いても動く。ただし背景画像の表示はブラウザによってはサーバー経由が必要。

1. 左の「条件」を確認・編集し，**探索実行**（既定条件で 15〜35 秒程度）
2. 成立解の表をクリックすると，その解の配置が中央の図に表示される（列見出しクリックでソート）
   - 「赤移動」列 = 赤中心の現在位置 `R0` (39.1, 3.15) からの移動量 [mm] の最小値。この列で並べているときに行を選ぶと，移動量最小の配置で表示する（それ以外は余裕最大の配置）
3. 右のパネルで赤の歯数・青の x・赤の角度・緑の分岐を変えると，制約チェックが即時に更新される。「余裕最大」「赤の移動最小」ボタンで配置を自動調整

### 共有

右パネルの「**共有リンクをコピー**」で，いまの条件（全項目。既定値が後で変わっても同じ結果になる）・選択中の解と配置（赤歯数・青 x・赤角度・分岐）・背景図を含んだ URL を作る。スマホでは OS の共有メニューが開く。
リンクを開くと探索なしでその解が表示される（条件はその端末に保存され，URL の `#share=…` は消える）。

## 1. 歯車構成

| 色 | 役割 | 種類 | かみ合い |
|---|---|---|---|
| 赤 | 動力源（モーター駆動） | 平歯車・外歯車 | 緑一層目 |
| 緑 | 中間歯車 | 平歯車・外歯車，**二層構造可** | 赤・青（一層目），黄（二層目） |
| 青 | 出力1 | 平歯車・外歯車 | 緑一層目 |
| 黄 | 出力2 | 平歯車・**内歯車** | 緑二層目 |

二層構造では，一層目と二層目の歯数・モジュールを別々にできる。一層構造は「一層目 = 二層目」として扱う。

## 2. 確定した条件

| 項目 | 条件 |
|---|---|
| 速度比 | `n青 / n黄 = (z緑1 · z黄) / (z青 · z緑2) = 15` を **厳密一致**（整数で割り切れる組のみ） |
| モジュール | 3Dプリント前提で **任意**。**0.5 以上必須，1 以上が望ましい**。下限〜上限を刻みで走査（既定 **1.5〜2.0**，刻み 0.05）。大きめ優先 |
| 歯形 | 標準平歯車，圧力角 20°，歯末 1.0m，歯元 1.25m，転位なし |
| 最小歯数 | **12**（CNC・3Dプリント前提。17 はホブ創成での切り下げ限界。かみ合い干渉は未判定 → 8. 未確定事項） |
| 座標 | 黄中心 = 原点，右 +x，上 +y，mm |
| 青の中心 | `y = −22`，x は設計変数 |
| 黄の歯底円直径 | `m2·z黄 + 2.5·m2 ≤ 172` |
| 赤の配置（図4） | 紫円 φ32（赤と同心）⊂ 茶円 φ112（黄と同心）→ `|R| ≤ 40` |
| 水色部品（図3） | 各歯車の歯先円が部品 P1・P2 と 0.5 mm 以上離れる |
| 紫円 ↔ P1・P3 | 紫円 φ32（モーター）が P1（レバー）・P3（上部ブロック）と被らない（すき間 ≥ 0）。P3 は歯車とは干渉判定しない |
| 紫円 ↔ 球 | 黄の中心にある球 φ27 と紫円のすき間 ≥ 0.5 mm → `|R| ≥ 13.5 + 16 + 0.5 = 30` |
| 青の位置 | 中心 **27 ≤ x ≤ 35**（図2 の青の位置 x≈27 より右）。x < 0 側は考えない |
| 赤の位置 | 中心 y が現在位置（図2・図4 の赤中心 (39.1, 3.15)）から **±8** 以内 → `−4.85 ≤ y赤 ≤ 11.15` |
| 赤 ↔ 青（一層） | 同一面なので歯先円同士が 0.5 mm 以上離れる |
| 赤 ↔ 青（二層） | 既定では二層時も **赤と青の歯先円同士** が 0.5 mm 以上離れる（条件欄でオン/オフ）。オフにすると，赤は片持ちのため青歯車とは干渉を考えず，赤の歯先円と **青の軸 φ8** が 0.5 mm 以上離れればよい |

回転方向: 赤と青は同方向，青と黄は逆方向。赤の歯数は速度比に影響せず，配置にだけ関わる。

## 3. 仮定（GUI の条件欄で変更可）

| 項目 | 既定値 | 理由 |
|---|---|---|
| かみ合わない歯車同士・軸とのすき間 | 0.5 mm | 赤 ↔ 青（または青の軸） |
| 赤・青が黄の歯先円内に収まる | 確認する | 安全側 |
| 緑一層目が黄の歯先円内に収まる（二層時） | **確認しない** | 別の面なので外に出てよい（2026-10-10 指示） |
| 緑一層目の最外点の半径 | ≤ 90 mm | 外周ホイール外径 φ179.8 相当。探索を有限にするための仮の上限 |
| 内歯車の歯数差 `z黄 − z緑2` | ≥ 10 | インボリュート・トロコイド干渉の目安 |
| 黄の歯先円 > 基礎円 | 確認する | 内歯車のインボリュート成立条件 |
| 歯数上限 | 赤 60，青 100，緑 200 | 探索範囲の打ち切り |

## 5. アルゴリズム

1. **列挙**（`enumerate`）: `m1, m2, z黄, z緑2, z青` を走査し，速度比から `z緑1 = 15·z青·z緑2 / z黄` が整数となる組を抽出する。あわせて，配置に依存しない条件（黄の歯底円，歯数差，基礎円，黄の歯先円内への収まり）で絞り込む。
2. **配置判定**（`solveCombo`）:
   - 青 `B = (x, −22)` を x 方向に走査する。緑の中心 `G` は「原点中心・半径 `a緑黄` の円」と「B 中心・半径 `a緑青` の円」の交点（2分岐）。
   - 赤は G 中心・半径 `a緑赤` の円上にある。`|R| ≤ 40` となる円弧を解析的に求め，その上をサンプリングする。
   - 水色部品との距離は事前計算した符号付き距離場（0.25 mm 格子，誤差 < 0.1 mm）で O(1) 判定する。
   - 成立する赤歯数の一覧と，最小余裕が最大となる配置を記録する。
3. **局所最適化**（`optimizePlacement`）: 選択した解について，厳密な距離計算で最小余裕を最大化する（全域の粗探索の後にパターンサーチ）。
4. **評価**（`evaluate`）: 全制約の余裕（mm）を一覧化する。余裕 ≥ 0 で成立。

## 6. 探索結果（既定条件）

モジュール 1.5〜2.0，最小歯数 12，青 27 ≤ x ≤ 35，赤 y = 3.15 ± 8，紫円 ↔ P1・P3 非干渉，紫円 ↔ 球 φ27 すき間 0.5 mm，赤 ↔ 青 歯先円 非干渉で探索した。候補 14,561 組 → 成立 323 組（すべて二層，ブラウザで約 4 秒）。

| m1 | m2 | z赤 | z青 | z緑1 | z緑2 | z黄 | 黄df | 最小余裕 | 律速 | 赤中心 | 青 x |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1.8 | 1.85 | 12〜13 | 12 | 27 | 12 | 80 | 152.63 | 0.78 | C4 青 ↔ P2 | (33.0, 10.4) | 29.7 |
| 1.75 | 1.85 | 12〜16 | 12 | 27 | 12 | 80 | 152.63 | 1.65 | C7b 赤 y | (33.9, 9.5) | 30.4 |
| 1.7 | 1.7 | 12〜22 | 12 | 24 | 12 | 90 | 157.25 | 0.93 | C7a 青 x | (38.0, 8.9) | 34.1 |

- 両方のモジュールの上限は 1.8 / 1.85。赤を現在位置から動かさずに置ける解は 25 組（最大 m1 = m2 = 1.65，z赤 12，z青 12，z緑1 26，z緑2 13，z黄 90）。
- z緑2 = 12〜14 と黄 80〜90 の内歯車かみ合いは，標準歯車ではインボリュート干渉の条件（z緑2 ≥ 19〜20）を満たさない。外歯車同士も z = 12 は相手 24〜27 歯に対し干渉する（必要 14〜15）。

最小余裕は，配置に関わるすき間（C3〜C5）の最小値 [mm]。C2・C6 は成否判定のみに使う。

### 参考: 緑一層目を黄の内側に収める場合の m1 の上限

速度比から `d緑1 = 15 · d青 · (d緑2 / d黄)` が成り立つ（d は基準円直径）。緑は黄に内接するので，中心距離は `|G| = (d黄 − d緑2)/2`。このとき緑一層目の歯先の最外点は

```
|G| + d緑1/2 + m1 = d黄/2 + (d緑2/d黄)·(7.5·d青 − d黄/2) + m1
```

これが黄の歯先円（`d黄/2 − m2`）の内側に入るには `7.5·d青 < d黄/2`，すなわち **`d青 < d黄/15 ≈ 11.4 mm`** が必要になる。
青は 17 歯以上なので `m1 < 11.4/17 ≈ 0.67`。一層構造（d青 = d黄/15 ちょうど）でも同じ上限になる。

m1 ≥ 1 にするには，次のいずれかが必要:
- 緑一層目が黄の歯先円の外側（別の面）に出てもよい（C5d を外す）。ただし緑一層目の外端は半径 ≈ 86 mm 以上に達し，外周ホイール（半径 ≈ 90 mm）付近まで出る
- 青の歯数を 17 未満にする
- 黄の歯底円直径の上限（172 mm）を緩める
