# 歯車列 設計計算シート

赤（駆動）・緑（中間）・青（出力1）・黄（出力2，内歯車）の4歯車からなる歯車列について，
条件を満たす **モジュールと歯数の組み合わせ** をアルゴリズムで探索し，結果をブラウザ上の GUI で確認するツール。

## 使い方

```bash
python3 -m http.server 8765      # このディレクトリで実行
# ブラウザで http://127.0.0.1:8765/index.html を開く
```

`index.html` をそのまま開いても動く。ただし背景画像の表示はブラウザによってはサーバー経由が必要。

1. 左の「条件」を確認・編集し，**探索実行**（既定条件で 15〜35 秒程度）
2. 成立解の表をクリックすると，その解の配置が中央の図に表示される（列見出しクリックでソート）
3. 右のパネルで赤の歯数・青の x・赤の角度・緑の分岐を変えると，制約チェックが即時に更新される

### 図の操作

| 操作 | 内容 |
|---|---|
| ホイール | ズーム（カーソル位置中心） |
| 左ドラッグ | 移動 |
| ホバー | 図形の ID・名前・寸法・座標をツールチップ表示。歯車は m・z・直径・中心，部品は外形・範囲・輪郭上の点 |
| 右クリック ×2 | 2点間距離（L, Δx, Δy）を表示。中心点・頂点・円周・輪郭に吸着（Shift で吸着なし） |
| Esc / 計測クリア | 計測中の点の取消 / 計測の全消去 |
| 背景 | 図2・図3・図4 を同一座標で重ねて表示（不透明度変更可） |

### 図形 ID

| ID | 内容 |
|---|---|
| `Y` / `G1` / `G2` / `R` / `B` | 黄 / 緑一層目 / 緑二層目 / 赤 / 青 |
| `.d` `.da` `.df` `.c` | 基準円 / 歯先円 / 歯底円 / 中心（例 `B.da` = 青の歯先円） |
| `BR` / `PU` | 茶円 φ112 / 紫円 φ32 |
| `P1` / `P2` | 水色部品（レバー）/ 水色部品（箱）。`P1.v3` は頂点 |

## 1. 歯車構成

| 色 | 役割 | 種類 | かみ合い |
|---|---|---|---|
| 赤 | 動力源（モーター駆動） | 平歯車・外歯車 | 緑一層目 |
| 緑 | 中間歯車 | 平歯車・外歯車，**二層構造可** | 赤・青（一層目），黄（二層目） |
| 青 | 出力1 | 平歯車・外歯車 | 緑一層目 |
| 黄 | 出力2 | 平歯車・**内歯車** | 緑二層目 |

二層構造では，一層目と二層目の歯数・モジュールを別々にできる。一層構造は「一層目 = 二層目」として扱う。

## 2. 確定した条件

| 項目 | 条件 |
|---|---|
| 速度比 | `n青 / n黄 = (z緑1 · z黄) / (z青 · z緑2) = 15` を **厳密一致**（整数で割り切れる組のみ） |
| モジュール | 3Dプリント前提で **任意**。下限〜上限を刻みで走査（既定 0.4〜1.2，刻み 0.05）。**大きめ優先** |
| 歯形 | 標準平歯車，圧力角 20°，歯末 1.0m，歯元 1.25m，転位なし |
| 最小歯数 | 17（強度上） |
| 座標 | 黄中心 = 原点，右 +x，上 +y，mm |
| 青の中心 | `y = −22`，x は設計変数 |
| 黄の歯底円直径 | `m2·z黄 + 2.5·m2 ≤ 172` |
| 赤の配置（図4） | 紫円 φ32（赤と同心）⊂ 茶円 φ112（黄と同心）→ `|R| ≤ 40` |
| 水色部品（図3） | 各歯車の歯先円が部品 P1・P2 と 0.5 mm 以上離れる |

回転方向: 赤と青は同方向，青と黄は逆方向。赤の歯数は速度比に影響せず，配置にだけ関わる。

## 3. 仮定（GUI の条件欄で変更可）

| 項目 | 既定値 | 理由 |
|---|---|---|
| かみ合わない歯車同士のすき間 | 0.5 mm | 赤 ↔ 青 の歯先円 |
| 赤・青・緑一層目が黄の歯先円内に収まる | 確認する | 二層構造でも安全側 |
| 内歯車の歯数差 `z黄 − z緑2` | ≥ 10 | インボリュート・トロコイド干渉の目安 |
| 黄の歯先円 > 基礎円 | 確認する | 内歯車のインボリュート成立条件 |
| 青の x 範囲 | 0〜80 mm | 図3 で青は右側（傘歯車側）。左側に置く解を除く |
| 歯数上限 | 赤 60，青 100，緑 200 | 探索範囲の打ち切り |

## 4. 図から読み取った寸法

縮尺: 図2 の黄基準円 φ162 が半径 531 px → **6.556 px/mm**。外周ホイール（φ179.8）の半径が図2・図3・図4 で一致（589.5 px）するため，3枚とも同じ縮尺。

| 確認項目 | 図からの読み取り | 計算値 |
|---|---|---|
| 図2 緑中心（m=0.6 と仮定） | (57.13, −18.84) | (56.98, −18.80) |
| 図2 赤中心 | (39.05, 3.13) | — |
| 図2 青中心 | (27.15, −21.96) | y = −22 |
| 図2 点線円 | 半径 367 px = 56.0 mm | 茶円 φ112 |
| 図3 傘歯車中心の y | −22.0 | 青中心 y と一致 |

水色部品（図3，精度 ±0.15 mm 程度）:

| ID | 形状 | 範囲 |
|---|---|---|
| P1 | レバー（41頂点の多角形） | x −12.57〜18.24，y −14.34〜9.00 |
| P2 | 箱（矩形） | x 10.09〜20.15，y −42.18〜−32.11 |

頂点座標は `gearcore.js` の `PARTS` に記載。P1 の下側の矩形部（x −3.72〜3.45, y < −9）は，水色の着色が続いているためレバーの一部とみなした。

## 5. アルゴリズム

1. **列挙**（`enumerate`）: `m1, m2, z黄, z緑2, z青` を走査し，速度比から `z緑1 = 15·z青·z緑2 / z黄` が整数となる組を抽出する。あわせて，配置に依存しない条件（黄の歯底円，歯数差，基礎円，黄の歯先円内への収まり）で絞り込む。
2. **配置判定**（`solveCombo`）:
   - 青 `B = (x, −22)` を x 方向に走査する。緑の中心 `G` は「原点中心・半径 `a緑黄` の円」と「B 中心・半径 `a緑青` の円」の交点（2分岐）。
   - 赤は G 中心・半径 `a緑赤` の円上にある。`|R| ≤ 40` となる円弧を解析的に求め，その上をサンプリングする。
   - 水色部品との距離は事前計算した符号付き距離場（0.25 mm 格子，誤差 < 0.1 mm）で O(1) 判定する。
   - 成立する赤歯数の一覧と，最小余裕が最大となる配置を記録する。
3. **局所最適化**（`optimizePlacement`）: 選択した解について，厳密な距離計算で最小余裕を最大化する（全域の粗探索の後にパターンサーチ）。
4. **評価**（`evaluate`）: 全制約の余裕（mm）を一覧化する。余裕 ≥ 0 で成立。

## 6. 探索結果（既定条件）

候補 59,880 組 → 成立 22,552 組。小さい方のモジュールが大きい順の上位:

| m1 | m2 | 構造 | z赤 | z青 | z緑1 | z緑2 | z黄 | 黄df | 余裕 |
|---|---|---|---|---|---|---|---|---|---|
| 0.65 | 0.65 | 一層 | 18 | 17 | 84 | 84 | 255 | 167.38 | 4.35 |
| 0.6 | 0.6 | 一層 | 19 | 18 | 88 | 88 | 270 | 163.50 | 4.28 |
| 0.6 | 0.7 | 二層 | 17 | 17 | 85 | 81 | 243 | 171.85 | 0.15 |
| 0.6 | 0.8 | 二層 | 17 | 17 | 85 | 70 | 210 | 170.00 | 0.60 |
| 0.6 | 1.0 | 二層 | 17 | 17 | 85 | 56 | 168 | 170.50 | 0.40 |

- 一層構造では `z黄 = 15·z青 ≥ 255` となり，歯底円の制約から `m ≤ 172/257.5 = 0.668`。そのため上限は m = 0.65。
- 二層構造では黄側（m2）を最大 1.15 まで大きくできるが，赤・青側（m1）は 0.6 が上限。
