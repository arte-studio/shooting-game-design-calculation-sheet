# 歯車列 設計計算シート

赤（駆動）・緑（中間）・青（出力1）・黄（出力2，内歯車）の4歯車からなる歯車列について，
条件を満たす **モジュールと歯数の組み合わせ** をアルゴリズムで探索し，結果をブラウザ上の GUI で確認するためのツール。

> ステータス: 条件整理段階。図1〜図4 の受領待ち，および「8. 未確定事項」の回答待ち。

---

## 1. 歯車構成

| 色 | 役割 | 種類 | 備考 |
|---|---|---|---|
| 赤 | 動力源（モーター駆動） | 平歯車・外歯車 | 緑の一層目とかみ合う |
| 緑 | 中間歯車（動力伝達） | 平歯車・外歯車 | 赤・青・黄すべてとかみ合う。**二層構造可** |
| 青 | 出力1 | 平歯車・外歯車 | 緑の一層目とかみ合う |
| 黄 | 出力2 | 平歯車・**内歯車** | 緑の二層目とかみ合う |

- 緑を二層にする場合: 一層目（赤・青とかみ合う）と二層目（黄とかみ合う）で歯数・モジュールを別にできる。
- 一層構造の場合は 一層目 = 二層目 として扱う。

## 2. 記号

| 記号 | 意味 |
|---|---|
| `m1` | 一層目のモジュール（赤・青・緑一層目） |
| `m2` | 二層目のモジュール（緑二層目・黄） |
| `z_r, z_b, z_y` | 赤・青・黄の歯数 |
| `z_g1, z_g2` | 緑 一層目・二層目の歯数 |
| `d = m·z` | 基準円直径 |
| `R, B, G` | 赤・青・緑の中心座標（黄の中心 = 原点） |

座標系: 図の右 = +x，上 = +y，黄歯車中心 = 原点 (0, 0)，単位 mm。

## 3. 速度比条件

赤 → 緑(一層目) → 青，および 緑(二層目) → 黄 の経路より

```
n_b / n_y = (z_g1 · z_y) / (z_b · z_g2) = 15
```

- 一層構造なら `z_y / z_b = 15`。
- 回転方向: 青と黄は互いに逆回転（外歯車の中間歯車を介すと青は赤と同方向，内歯車の黄は緑と同方向）。
- 赤の歯数 `z_r` は出力比に影響しない（中心距離・配置にのみ影響）。

## 4. 幾何条件

歯形の前提（仮）: 標準平歯車，圧力角 20°，転位なし，歯先 = 1.0m，歯元 = 1.25m。

| 項目 | 外歯車 | 内歯車（黄） |
|---|---|---|
| 歯先円直径 `da` | `d + 2m` | `d − 2m` |
| 歯底円直径 `df` | `d − 2.5m` | `d + 2.5m` |

### 4.1 かみ合い（中心距離）

| ペア | 中心距離 |
|---|---|
| 緑–黄（内接） | `|G| = m2·(z_y − z_g2) / 2` |
| 緑–青 | `|B − G| = m1·(z_g1 + z_b) / 2` |
| 緑–赤 | `|R − G| = m1·(z_g1 + z_r) / 2` |

### 4.2 配置・寸法の制約

| # | 条件 | 式 |
|---|---|---|
| C1 | 青の中心 y 座標 | `B.y = −22` （`B.x` は設計変数） |
| C2 | 黄の歯底円直径 | `m2·z_y + 2.5·m2 ≤ 172` |
| C3 | 赤の配置（図4） | 紫円 φ32（赤と同心）が茶円 φ112（黄と同心）の内側 → `|R| + 16 ≤ 56`，すなわち `|R| ≤ 40` |
| C4 | 青の歯先円と水色部品（図3）の非干渉 | 図3 受領後に形状を定義。`B.x` が大きいほど許容歯先円は大きくなる |
| C5 | 歯車同士の非干渉 | 赤–青の歯先円が重ならない，赤・青の歯先円が黄の歯先円（内側）からはみ出さない 等（詳細は未確定事項 Q5） |
| C6 | 内歯車の干渉 | 緑二層目と黄の歯数差がインボリュート干渉・トロコイド干渉を起こさない範囲（Q4） |

### 4.3 自由度と探索の考え方

1. 歯数・モジュールを決めると中心距離 `|G|`，`|B−G|`，`|R−G|` が決まる。
2. `B = (x_b, −22)` とし，原点中心半径 `|G|` の円と `B` 中心半径 `|B−G|` の円の交点として `G` が決まる（最大2解）。
3. `R` は `G` 中心半径 `|R−G|` の円上で，`|R| ≤ 40` かつ非干渉となる角度範囲を探す。
4. `x_b` を走査し，C1〜C6 をすべて満たす配置が存在する組み合わせを「成立解」とする。

## 5. 参考: 不成立だった配置（図2）

| 歯車 | 基準円直径 [mm] |
|---|---|
| 赤 | 14.4 |
| 青 | 18 |
| 緑 | 42 |
| 黄 | 162 |

- 比 `162 / 18 = 9` で，目標の 15 になっていない（一層構造の場合）。
- 例えば m = 0.6 なら 赤24・青30・緑70・黄270 歯に相当。

## 6. アルゴリズム（予定）

- 入力: 条件（上記数値・モジュール候補・歯数範囲・干渉形状）
- 処理: モジュール × 歯数の全探索 → 速度比で絞り込み → 幾何配置を数値探索 → 制約チェック
- 出力: 成立解の一覧（評価値でソート）と，各解の座標・寸法

## 7. GUI（予定）

ブラウザで開ける静的ページ（ローカルで `index.html` を開くだけで動作）。

- 条件の表示・編集，探索の実行，成立解の一覧表示
- 選択した解の歯車配置を図（基準円・歯先円・歯底円，水色部品，紫円・茶円）で描画
- **距離計測**: 異なる2点を右クリックで指定すると，その2点間距離を表示
- **ホバー情報**: カーソルを点や図形に当てると，図形 ID・寸法・座標をツールチップ表示
- ズーム・パン
